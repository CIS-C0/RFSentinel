Install

Android 8.0 or newer on an ARM phone, 64-bit or 32-bit (practically every Android phone). One signed APK from GitHub Releases, about 44 MB.

{{DOWNLOAD_SVG}}Download APK All releases & changelog

Steps

  1. On your phone, tap Download APK above, or open the latest release and under Assets tap the file ending in -release.apk. Don't pick the "Source code" archives.
  2. Open the downloaded file from the notification, or from Files → Downloads.
  3. If Android blocks it as an unknown source, tap Settings, enable Allow from this source, go back and tap Install.
  4. Open RF Sentinel. The setup wizard walks through theme, region preset, alerts, camera download radius, screen behaviour and permissions.
  5. Tap Start scanning and grant location and Nearby devices.

Only free software? The same release also has a file ending in -foss.apk (about 23 MB): no Mapbox map (the map is OpenFreeMap), and the few USB WiFi adapters that need non-free chip firmware ask before downloading it from kernel.org. Either file replaces the other.

With Obtainium

Obtainium installs apps straight from their GitHub releases and keeps them updated. Install Obtainium, then on the phone tap the Get it on Obtainium badge above. It adds RF Sentinel with the -release.apk already picked. For the free-software build, use this link for the FOSS APK instead.

Adding it by hand: in Obtainium tap Add app, enter https://github.com/CIS-C0/RFSentinel and set APK filter to -release\.apk$ (or -foss\.apk$). Obtainium installs the same signed APKs as GitHub, so it updates over a copy you installed by hand and the other way round.

Updating

Settings → Lists, tools & about → Check for updates asks GitHub for the latest release and links its APK (only when you tap it). Install the newer APK over the existing one. History, watchlist and settings are kept. Every release is signed with the same key; Android refuses an update signed with a different one.

Android Auto

In a real car, Android Auto only shows Car App Library apps like RF Sentinel when they're installed from a trusted store (Google Play or ONE store); its Unknown sources setting doesn't cover them. The GitHub APK's car screens run on Google's Desktop Head Unit emulator, and once that setting is on it gets a media-style RF Sentinel screen and alert messages in the car. More on Android Auto.

Battery settings

On phones with aggressive battery management (Samsung, Xiaomi, OnePlus, Huawei), set RF Sentinel's battery usage to Unrestricted. Settings has a shortcut.

Build from source

Android Studio, or JDK 17+ with the Android SDK (platform 37).

git clone https://github.com/CIS-C0/RFSentinel
cd RFSentinel
./gradlew assembleDebug                 # app/build/outputs/apk/debug/
./gradlew testDebugUnitTest lintDebug   # tests and lint
