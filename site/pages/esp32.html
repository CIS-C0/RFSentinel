rf_sentinel / esp32

ESP32 boards

An ESP32 with a decent antenna hears further than a phone and can see things Android hides. RF Sentinel merges what the board reports into its own list, marked with a blue ESP32 badge.

USB

Plug the board into the phone with a USB OTG cable while scanning and allow USB access on the first prompt. Native-USB boards (ESP32-S2 / S3 / C3 / C6) and boards with CP210x or CH340 USB bridges work. RF Sentinel never sends OUI-Spy anything, and only asks GhostESP to scan and list networks. Settings shows the board's status.

Bluetooth (OUI-SPY App-Controlled)

  1. Power the board and start scanning in RF Sentinel.
  2. Settings → Pair OUI-SPY board → pick OUI-SPY-xxxx.
  3. Pair only there, not in Android's Bluetooth settings: the board keeps no pairing keys, so a phone-side bond breaks the link. The app tells you to tap Forget if it finds one.

While scanning, RF Sentinel switches on the board's Flock-BLE, Flock-WiFi, Sky Spy and Detector engines and switches them off when scanning stops. By default it also runs the Wardrive survey engine so the board relays every WiFi network and Bluetooth device; those go through RF Sentinel's own watchlist, presets and rules. In that mode the board sends standard WiFi probe requests, so turn off OUI-SPY: relay every network and Bluetooth device to keep it purely listening. The board's UniPwn, PCAP and Foxhunter engines are never used.

The status line under Scanning shows connecting… / live · N reports; the ESP32 filter chip lists only what the board reported.

Questions

Which ESP32 board should I buy?

Any board the firmware supports: XIAO ESP32-S3, ESP32-S3 DevKitC, LilyGO T-Dongle-S3 and others are targets of OUI-Spy. An external antenna connector (u.FL / IPEX) is worth having for range.

How do I flash OUI-Spy?

Follow the firmware's own README (PlatformIO or its flash script). RF Sentinel doesn't flash boards.
