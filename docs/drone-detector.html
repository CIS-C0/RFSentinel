Remote ID drone detector

Drones flying under FAA and EU Remote ID rules broadcast their identity and position in the clear. RF Sentinel decodes the broadcast and puts every drone and its operator on a map.

ASTM F3411 messages

  • Basic ID (0): serial number or registration, UA type.
  • Location / Vector (1): latitude, longitude, altitude, height, speed, vertical speed, heading.
  • Self ID (3): free-text description.
  • System (4): operator / take-off position, area count.
  • Operator ID (5): registered operator ID.
  • Message Pack (0xF): several of the above in one extended advert.

Message layout follows opendroneid-core-c (Apache-2.0).

In the app

  • Live map of each drone with heading, altitude and speed, plus its operator.
  • Drone overhead alert (95) when one is within 200 m horizontally of you, once per drone per 5 minutes.
  • Drone and operator positions open in your maps app; in Android Auto, Navigate hands them to your navigation app.
  • Drones filter chip with a live count.

Questions

Can it detect DJI drones without Remote ID?

Not their video / control link: DJI OcuSync is a proprietary wideband link a phone can't decode. DJI aircraft sold under Remote ID rules broadcast standard Remote ID, which is what RF Sentinel reads.

How far away can it see a drone?

Remote ID over Bluetooth is designed for a few hundred metres in the open; phones with LE Coded PHY hear the long-range variant further. WiFi Beacon Remote ID usually carries further than legacy Bluetooth.
